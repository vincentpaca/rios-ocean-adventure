# Rio's Ocean Adventure

A Starting ocean slice for a 5-year-old browser game — swim, catch fish, cook, and explore.

## Open locally

1. Open a terminal in this folder.
2. Start a simple static server, for example:

   ```bash
   python3 -m http.server 8080
   ```

3. In your browser, go to `http://localhost:8080`.

You can also open `index.html` directly in a browser if your setup allows local file scripts.

## Controls

**Keyboard**

- Move: Arrow keys or WASD
- Catch: Space
- Cook: E

**Touch**

- Move: on-screen joystick
- Catch: fish button
- Cook: pot button
